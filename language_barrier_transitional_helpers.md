# Language barrier transitional helpers

Dictionary for dictation / mishearing.

**Always check context first.** A mapping is a guess, not a command. If I heard “schools”, it might mean “tools” — but if the sentence is actually about a school, campus, or attendance system, it means schools. Same for “prop” → “cropped”: use cropped for photos; keep prop if it is a component prop or a theatre prop.

## How to add a row

When a mishearing is confirmed in chat, append a row. Do not replace an older mapping; add a more specific row if needed.
