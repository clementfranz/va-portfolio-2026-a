# Logistics VA Portfolio

Personal portfolio for ClementFranz, a Logistics & Operations VA based in City of San Fernando, LU, Philippines. Static Next.js site — no database, no auth, no CMS.

## Update content

Edit one file: `src/data/profile.ts`

Drop your resume at `public/assets/resume.pdf`.

To swap the hero photo, replace `public/assets/portrait.jpg` (or change `portraitPath` in the profile file).

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
